# Свои звуки Asterisk

Папка смонтирована в контейнер как `/var/lib/asterisk/sounds/custom` (только чтение).

| Файл | Где звучит |
|---|---|
| `lang-menu.wav` | меню выбора языка на номере 5001 одним файлом: «Pentru limba română apăsați 1. Для русского языка нажмите 2» |
| `lang-menu-ro.wav` + `lang-menu-ru.wav` | то же меню двумя файлами — играют подряд (сначала RO, потом RU); используются, если нет `lang-menu.wav` и есть оба |

Формат: WAV, 8000 Гц, моно, 16 бит (PCM). Нажать 1 или 2 можно в любой момент, не дослушав. Пока файлов меню нет, меню пропускается и звонок сразу идёт к RO-агенту.

Перевести любой файл в нужный формат (на сервере или где есть ffmpeg):

    ffmpeg -i исходник.mp3 -ar 8000 -ac 1 -sample_fmt s16 lang-menu.wav

Новый файл подхватывается сразу, перезапуск не нужен.
