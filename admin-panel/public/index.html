Доступ к панели
Панель сама перезапустится. После этого войди с новым логином/паролем. ВАЖНО: старые вкладки браузера кэшируют прежний пароль — закрой окно полностью и открой заново.
?Сохранить — записывает изменения в файл .env. Сервисы пока продолжают работать со старыми значениями — чтобы применить, нажми «Применить». ?Применить — панель сама находит сервисы, запущенные со старыми значениями .env, и пересоздаёт только их; при смене адреса/ключа тулзов или выключателей синхронизирует тулзы Ultravox. Перед этим показывает план. Описания и значения по умолчанию — из .env.example. Пустое поле = значение по умолчанию. Секреты замаскированы: оставь «••••», чтобы не менять.
